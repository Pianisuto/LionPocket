# LionPocket v0.3.15

O Dashboard mostra quanto pode gastar hoje considerando o dia mais apertado do mês, a margem de segurança e os reforços dos objetivos.

- “Pode gastar hoje” fica dentro de “Saldo projetado” no Desktop, com acesso à linha do tempo. Os quatro cards mantêm uma altura compacta e passam para duas colunas conforme a largura disponível.
- O detalhe mostra o saldo após cada movimento, com um único cabeçalho “Saldo” e destaque no ponto mais apertado, seguindo as cores do app.
- Desktop e Android compartilham o cálculo diário: contas saem antes das entradas do mesmo dia, e valores negativos mostram quanto falta. A disponibilidade aparece somente no mês atual.
- Margem de segurança mensal e reforços mensais dos objetivos entram no dinheiro protegido. Os valores derivados não criam entidades novas de sincronização.
- Configurações organizam dados locais e sincronização opcional. Desvincular o servidor preserva os dados locais.

## Atualização

Atualize **servidor de sincronização, Desktop e Android em conjunto**. O servidor passa a anunciar os escopos `monthlyPlanning` e `goalMonthlyReinforcement`; clientes antigos bloqueiam a sincronização ao encontrar esses recursos desconhecidos. O uso offline e os dados locais ficam preservados durante a incompatibilidade.

Android usa versionCode 8 e a mesma chave permanente de produção. Atualize por cima da instalação existente para preservar o banco e o Keystore.

Para instalações anteriores à v0.3.13, continua obrigatório recriar o servidor de sync conforme as [notas da v0.3.13](https://github.com/Pianisuto/LionPocket/blob/v0.3.13/docs/releases/v0.3.13.md). Um servidor já recriado com a v0.3.13 mantém seus volumes e vínculos nesta atualização.

## Artefatos e validação

- `LionPocket-Android-0.3.15.apk`: assinatura permanente de produção.
- `lionpocket_0.3.15_amd64.deb`: Zorin/Ubuntu/Debian x64.
- `LionPocket-Linux-x64-0.3.15.zip`: Linux portátil x64.
- `build-manifest.json` e `SHA256SUMS.txt`: fonte e integridade dos artefatos.

A preparação usa `npm run validate:full` para integração, pacotes Linux normal/beta e Android em AVD descartável. GitHub Actions permanece desativado. Instalação, protocolo e DPAPI no Windows exigem host Windows descartável e não são cobertos pelo ensaio Linux.
