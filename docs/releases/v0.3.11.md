# LionPocket v0.3.11

Primeira release preparada para usar o conjunto atual do LionPocket no dia a dia com **Android + Desktop + servidor self-hosted** na mesma versão.

## O que entra

- sincronização local-first entre Desktop e Android;
- servidor próprio com PostgreSQL, Keycloak/OIDC e HTTPS;
- E2EE do conteúdo financeiro;
- pareamento e aprovação de novos aparelhos;
- recovery code e rotação/revogação;
- backup/verify/restore do servidor;
- recuperação crash-safe do aparelho âncora após restore;
- login e painel de sincronização integrados ao tema Juba;
- builds Linux, Windows e Android normal.

## Android — atenção na primeira instalação desta release

A v0.3.11 inaugura a **identidade permanente de assinatura Android**.

Instalações antigas de desenvolvimento usavam uma chave pública de debug. O Android não permite atualizar diretamente dessa chave para a chave definitiva mantendo o mesmo package ID.

Se você já usa o LionPocket Android e possui dados locais:

1. Abra **Dados locais** no app antigo.
2. Escolha **Salvar backup SQLite em arquivo** e guarde o arquivo fora do aplicativo.
3. Confira que o arquivo existe no local escolhido.
4. Somente então desinstale a instalação antiga.
5. Instale `LionPocket-Android-0.3.11.apk`.
6. Abra **Dados locais → Escolher arquivo local**.
7. Selecione o backup SQLite e faça a restauração completa.
8. Depois configure a sincronização com seu servidor.

As releases Android seguintes assinadas com esta mesma identidade poderão atualizar normalmente por cima da v0.3.11.

## Desktop

### Zorin / Ubuntu / Debian

Baixe o arquivo:

`lionpocket_0.3.11_amd64.deb`

e instale:

```sh
sudo apt install ./lionpocket_0.3.11_amd64.deb
```

O banco existente do Desktop fica no perfil do usuário e não é removido pelo pacote.

Também há ZIP portátil.

### Windows

Use `LionPocket-Instalador.exe`. O release também contém ZIP, NUPKG e `RELEASES` para o mecanismo Squirrel existente.

O executável Windows ainda não possui assinatura Authenticode pública; o Windows pode exibir aviso de reputação.

## Servidor próprio / homelab

Use **a mesma tag desta release**:

```sh
git clone --branch v0.3.11 --depth 1 https://github.com/Pianisuto/LionPocket.git
cd LionPocket/deploy/self-hosted
cp .env.example .env
```

Crie dois DNS apontando para o homelab, por exemplo:

- `sync.seudominio.com`
- `auth.seudominio.com`

Edite somente `.env`, execute:

```sh
./lpctl init
./lpctl up
./lpctl status
./lpctl user create seuusuario
```

Com Caddy, portas 80/443 públicas e DNS corretos, os certificados HTTPS são emitidos automaticamente.

No app normal informe somente:

`https://sync.seudominio.com`

O LionPocket descobre o endpoint de autenticação e os demais parâmetros.

Consulte `docs/self-hosting.md` para backup, restore, proxy existente e troubleshooting.

## Limitações conhecidas

- Android sincroniza automaticamente enquanto o app está ativo; background sync ainda não foi implementado.
- O segundo aparelho que ficou em uma geração antiga após um restore do servidor ainda exige reconexão futura; seus dados permanecem preservados.
- Windows não tem Authenticode definitivo.
- Não existe LionPocket Cloud público nesta release.
