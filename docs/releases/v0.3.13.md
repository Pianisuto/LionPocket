# LionPocket v0.3.13

Pareamento entre aparelhos passa a usar somente LPV2, com convite temporário e aprovação no aparelho autorizado. Recovery usa seu próprio pacote durável LPR1 e código de recuperação.

- Desktop → Android: mostrar QR, escanear no celular, Conectar e aprovar no Desktop.
- Android → Desktop: compartilhar/copiar link; abrir `lionpocket://pair/...` no computador, Conectar e aprovar no celular. O Desktop instalado recebe o link tanto fechado quanto aberto, com uma única instância.
- Copiar/colar convite continua como fallback. O novo aparelho não precisa de OIDC ou digitar fingerprint; o código curto é comparado visualmente.
- Dispositivos aprovados usam o transporte assinado atual.
- “Servidor de sincronização recriado” distingue a fonte de verdade do aparelho secundário. A intenção sobrevive a reinício, e o secundário é conduzido ao pareamento, sem criar outro cofre.

## Instalação self-hosted limpa obrigatória

**Esta atualização exige recriar o servidor de sync em volumes novos e vazios.** Não atualize containers sobre os volumes anteriores e não restaure o banco antigo de sync na nova instalação. Clientes anteriores não são suportados.

Antes de alterar qualquer vínculo, preserve e verifique backups locais e do servidor anterior. Escolha apenas um aparelho como fonte de verdade:

1. Fonte de verdade: **Servidor recriado → Usar este aparelho como fonte de verdade → backup → Criar novo cofre usando estes dados → primeiro sync**.
2. Secundários: **Servidor recriado → Conectar este aparelho a um cofre já recriado → backup → convite LPV2 → aprovação → primeiro sync**.

Os bancos financeiros locais são preservados. A desvinculação limpa somente metadata de sync depois de um backup completo. Bases que já divergem devem ser conferidas antes de parear; guardá-las em backup permite revisão sem perder dados.

## Downloads

- Zorin/Ubuntu/Debian x64: `lionpocket_0.3.13_amd64.deb`.
- Linux portátil x64: `LionPocket-Linux-x64-0.3.13.zip`.
- Android: `LionPocket-Android-0.3.13.apk`, versionCode 6, assinado pela chave permanente de produção.
- `SHA256SUMS.txt` e `build-manifest.json` identificam conteúdo, versão e SHA da fonte.
- Servidor: código-fonte da tag `v0.3.13`, compilado localmente.

Android pode atualizar por cima somente se o APK instalado tiver o mesmo certificado permanente. Instalações assinadas pela chave de desenvolvimento exigem exportação/verificação do SQLite e migração de instalação; não desinstale sem backup. Consulte a documentação de assinatura e self-hosting desta tag.

Esta publicação contém Linux e Android. Um novo instalador Windows não foi validado/publicado nesta execução Linux.
